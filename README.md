# ETF 期权助手 — HTML 本地交互原型

**版本**：v1.5  
**关联 PRD**：[PRD-ETF期权行情及交易辅助工具.md](../../Product%20manager/PRD-ETF期权行情及交易辅助工具.md)

## 如何打开

直接用浏览器打开本目录下的 `index.html`，或执行 `start index.html`。

## 导航结构（v1.5）

首页 · IV 热力图 · T 型报价 · 交易列表 · 设置

（波动率锥已移除，延期开发）

## 刷新策略

| 页面 | 自动刷新 | 手动刷新 |
|------|----------|----------|
| 首页 | ✅ 按「首页刷新频率」 | 进入首页 |
| IV 热力图 / T 型报价 | ❌ | 进入页面、顶栏「刷新」、切换标的 |
| 交易列表 | ❌ | 随报价刷新联动 |

## 设置页

| 字段 | 可编辑 | 默认 |
|------|--------|------|
| 无风险利率 r | ✅ | 0.02 |
| 分红率 q | ✅ | 0 |
| 行情刷新频率 | ✅ | 8s（预留，期权链不自动轮询） |
| 首页刷新频率 | ✅ | 30s |

修改后自动保存至 `localStorage`。
