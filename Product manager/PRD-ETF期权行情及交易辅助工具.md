## 1. 文档概述

### 1.1 背景

用户当前通过 Jupyter Notebook（`期权行情报价工具.ipynb`）完成 A 股 ETF 期权的行情查看、IV/Greeks 计算和热力图分析，但存在以下痛点：

- 交互分散在 Notebook 单元格中，无法形成稳定的产品化工作流
- 缺乏统一的导航与交易辅助界面
- 行情数据源（尤其 Sina）存在反爬与稳定性风险
- 从「看行情」到「组交易」需要手动抄写合约信息，效率低

### 1.2 产品定位

一款 **本机部署的 BS 架构 Web 工具**，面向 A 股 ETF 期权交易者，提供：

- 多标的期权行情可视化（T 型报价 + IV 热力图）
- 基于热力图/报价表的快速选腿与交易列表管理
- 组合级 Greeks 与权利金预估
- 为后续 miniQMT 实盘下单预留接口

**产品性质**：交易**辅助**工具（MVP 不直连下单）

### 1.3 目标用户

| 用户类型 | 特征 | 核心诉求 |
|----------|------|----------|
| 主用户 | 有 ETF 期权实盘经验，熟悉 IV/Delta | 快速扫全链波动率结构、高效组腿 |
| 扩展用户 | 个人量化/期权交易者 | 直观热力图、可导出交易清单 |

## 2. 产品目标

### 2.1 业务目标

1. 将 Notebook 中已验证的分析能力产品化，形成可日常使用的 Web 界面
2. 用热力图替代「逐格扫 T 表」，提升识别波动率机会的效率
3. 打通「看行情 → 选合约 → 组交易清单」闭环，减少手工操作

### 2.2 成功指标（MVP）

| 指标 | 目标 |
|------|------|
| 标的切换至热力图展示 | ≤ 3 秒（含首次拉取） |
| 全链行情刷新周期 | **不自动刷新**（热力图/T 型报价）；仅进入页面或手动刷新 |
| 首页行情刷新周期 | 可配置，默认 30 秒 |
| 三态点选到交易列表同步 | 即时（< 200ms 前端响应） |
| 组合 Greeks 汇总准确性 | 与 Notebook `price_to_iv` 结果一致 |
| 非交易时段可用性 | 可查看上次缓存快照 |

## 5.0 定价与计算基准（全局）

**所有分析参数均以中间价（Mid）为输入计算**，除非字段说明中另有标注（如「委托价」按报价方式推导）。

| 定义 | 公式 |
|------|------|
| **中间价** | `Mid = (Bid1 + Ask1) / 2` |
| **适用范围** | IV 反解、Delta / Gamma / Theta / Vega、热力图格子数值与着色、T 型报价 Greeks 列、交易列表默认 Greeks 展示 |

**说明**

- 买一 = `Bid1`，卖一 = `Ask1`；无单边报价时该合约标记为无效，格子置灰
- 交易列表中的 **委托价** 仍按用户选择的报价方式（对手价/挂单价/中间价）计算，与上述「分析用中间价」区分
- UI 页脚或设置页展示提示：「IV 与 Greeks 基于中间价计算」

---

用户打开应用后首先进入本页，**同时展示所有支持的 ETF 标的**，无需先选标的。

#### 5.2.1 标的卡片（每个 ETF 一块）

支持标的：**510050（50ETF）、510300（300ETF）、510500（500ETF）**

每张卡片包含：

| 区域 | 内容 |
|------|------|
| 标题行 | 标的代码、名称、现价、涨跌幅（红/绿） |
| 摘要指标 | HV20 / HV60 / HV120；主力到期月；可交易合约数量 |
| **日线图** | 最近 **60 个交易日** **蜡烛图**（OHLC：开盘/最高/最低/收盘），涨红跌绿（或涨绿跌红，与 A 股习惯一致），可悬停查看单日四价 |
| 操作 | **进入分析** 按钮 → 跳转 IV 热力图并带入该标的 |

#### 5.2.2 日线图规范（蜡烛图）

- 每根 K 线包含：**影线**（最高—最低）+ **实体**（开盘—收盘）
- 收盘 ≥ 开盘：阳线；收盘 < 开盘：阴线
- 不支持用柱状图/折线图替代蜡烛图
- 高度 160–200px；支持横向滚动查看更多历史

#### 5.2.3 布局

- 三列卡片并排（宽屏）或纵向堆叠（窄屏）
- 日线图高度建议 160–200px，占卡片主体区域
- 卡片底部可显示「上次更新 HH:MM:SS」

#### 5.2.4 交互

- 点击卡片任意区域或「进入分析」→ 跳转热力图页，顶栏标的同步切换
- 首页数据刷新周期：可配置（默认 30s），**仅首页自动刷新**

### 5.3 IV 热力图（P0 — 核心功能）

#### 5.3.1 矩阵结构（v1.3 修订）

**坐标轴**

| 维度 | 规则 |
|------|------|
| **纵轴（Y）** | **4 个挂牌到期月**，按上交所 ETF 期权规则动态计算：**当月、下月、随后两个季月**（季月 = 3/6/9/12 月）。例：2026 年 9 月 → 9月、10月、12月、2027年3月 |
| **横轴（X）** | 行权价，按档位从左到右递增；**仅展示现价 S 的 ±20% 范围内**的有效档位 |

**行权价取档规则**

| 标的现价 S（元） | 行权价间距（元） |
|------------------|------------------|
| S ≤ 3 | 0.05 |
| 3 < S ≤ 5 | 0.10 |
| 5 < S ≤ 10 | 0.25 |
| 10 < S ≤ 20 | 0.50 |
| 20 < S ≤ 50 | 1.00 |
| 50 < S ≤ 100 | 2.50 |
| S > 100 | 5.00 |

- 展示区间：`[S × 0.8, S × 1.2]`，按上表间距向上/向下取整到最近档位
- 超出 ±20% 的合约不在热力图中展示（T 型报价可展示更全链，MVP 与热力图同范围）

**表头与列对齐**

- 表头每个行权价占 **独立一列**（`1 行权价 = 1 列`），与下方格子列宽一致
- 禁止用 `colspan` 合并表头导致列错位
- 现价竖线占独立窄列，位于购/沽分界处

**购/沽合表规则（仅虚值合约）**

以标的现价 **S** 为分界（示例：S = 7.689）：

| 区域 | 合约类型 | 行权价条件 | 说明 |
|------|----------|------------|------|
| **竖线左侧** | 沽（Put） | **K < S** | 虚值看跌 |
| **竖线右侧** | 购（Call） | **K ≥ S** | 虚值看涨（含平值档） |

- 整张热力图为 **一张表**，不再左右拆成两个独立矩阵
- 在 **K 跨越 S 的列边界** 处绘制 **竖向参考线**，标注「现价 S」
- 平值档：取 **K ≥ S 的最小行权价** 作为购方平值列；**K < S 的最大行权价** 作为沽方最靠近现价列
- **不展示** 实值合约（购 K<S、沽 K>S）及无报价档位
- **默认不展示** 非标准（除权调整）合约；用户可在 **设置页** 开启（见 5.3.8、5.6）

**示意图**（2026 年 9 月，S = 7.689，间距 0.25，±20%）

```
行权价 →  6.25沽 ... 7.50沽 │ 7.75购 ... 9.00购
           ───────── 沽（K<S）───────────────│────────── 购（K≥S）──────────
9月        [IV/Δ] [IV/Δ] ...              [IV/Δ]│[IV/Δ] [IV/Δ] ...
10月       ...
12月       ...
3月(季)    ...
                              现价 7.689 ↑
```

#### 5.3.2 着色规则

1. 取标的过去 **10 年日线**，计算 **20 日滚动历史波动率** 序列
2. `vmin` = 该序列 **20% 分位**；`vmax` = **80% 分位**
3. 格子颜色映射 **中间价 IV**（`IV_mid`）：越低越浅，越高越深
4. 分位值按标的缓存，每日更新

#### 5.3.3 格子内容

每个有效格子显示两行：

```
IV (23.45%)
Δ 0.382
```

- IV、Delta 均基于 **中间价** 计算（见 5.0）

#### 5.3.4 空格子

- 深度虚值无报价，或 IV 无解：灰色 `--`，不可点击

#### 5.3.5 交互：三态点选

| 点击次数 | 状态 | 视觉 | 交易列表 |
|----------|------|------|----------|
| 第 1 次 | 做多 | 绿色边框 | 新增，方向=做多 |
| 第 2 次 | 做空 | 红色边框 | 更新，方向=做空 |
| 第 3 次 | 移除 | 恢复默认 | 从列表删除 |

- 与 T 型报价表、交易列表实时联动高亮

#### 5.3.6 页面布局

- **上下分栏**：上方报价区、下方交易列表区 **各自独立滚动**
- **上方报价区**：热力图主体（可横向/纵向滚动）、图例与提示
- **下方交易列表区**：固定于视口底部（高度约 32vh，可内部滚动），操作栏与汇总始终可见

> T 型报价页（5.4）采用相同分栏规则。

#### 5.3.8 标准合约 / 非标准合约切换（P1）

**背景**

上交所 ETF 期权在标的 **除权除息** 后，会挂牌 **非标准合约**（又称调整合约、临调合约）。其合约简称常带字母尾缀（如 `50ETF购9月2650A`），行权价、合约单位可能与同期标准合约并存。日常分析以 **标准合约** 为主；除权窗口期部分交易者需要查看调整合约的 IV 与流动性。

**定义**

| 类型 | 说明 | 识别规则（实现参考） |
|------|------|----------------------|
| **标准合约** | 常规挂牌、行权价按间距表取档的合约 | 合约简称 **无** 除权调整尾缀字母；或数据源 `is_standard=true` |
| **非标准合约** | 因除权除息产生的调整合约 | 合约简称行权价后带 **单字母尾缀**（如 `A`、`M`）；或数据源 `is_adjusted=true` / 上交所合约列表字段标识 |

> 注：具体字段以 Adapter 层解析为准（上交所当日合约列表 + 行情链）；PRD 以 **用户可感知的「标准 / 非标准」二分** 为准，实现不得依赖单一数据源硬编码。

**Toggle 行为（设置页，见 5.6）**

| 项 | 规则 |
|----|------|
| 控件位置 | **设置页** Switch：「显示非标准合约」 |
| 默认值 | **关**（仅标准合约，与当前线上行为一致） |
| 作用范围 | **IV 热力图** + **T 型报价**（全局同步） |
| 持久化 | 写入 **设置 API** / `settings.json`（与 r、q 同级）；前端各页读取同一配置 |
| 保存后刷新 | 用户 **保存设置** 后，若开关状态相对上次保存发生变化，提示「请刷新热力图/T 型报价以加载新合约范围」；**不自动发起** 期权链请求 |
| 分析页提示 | 开关为开时，热力图/T 型报价图例区只读显示：`含非标准合约` |

**数据拉取策略（减少接口调用，P1 必达）**

| 开关状态 | 后端期权链请求范围 | 说明 |
|----------|-------------------|------|
| **关**（默认） | **仅标准合约** | 解析链后过滤 `is_standard=true`；**不对非标准合约批量询价**（如不发起额外 Sina `CON_OP_*` 请求） |
| **开** | 标准 + 非标准 | 在标准链基础上追加非标准合约及其报价 |

实现要点：

1. 期权链接口增加查询参数或读取设置：`include_non_standard=false|true`（默认 `false`）
2. **关**：仅对矩阵内 **虚值标准合约**（±20% 档位）拉取/保留报价，避免全链 ~300+ 合约无效请求
3. **开**：在 2 的基础上追加非标准虚值合约报价；仍遵守 ±20% 与虚值过滤
4. 切换开关并保存后，由用户 **手动刷新** 或 **重新进入页面** 触发新范围请求；禁止后台静默全量重拉
5. 缓存键区分：`option_chain_sina_std` / `option_chain_sina_full`（或同等语义），避免关→开 时误用仅标准缓存

**矩阵展示规则（开关 = 开）**

1. **行权价列不变**：仍按 5.3.1 标准间距与 ±20% 生成横轴；不因非标准合约新增列
2. **格子映射（同列并存，已确认）**：
   - 非标准合约按 **数值行权价** 映射到最近的标准列
   - 同一 `(到期月, 行权价列, 购/沽)` 同时存在标准与非标准且均有报价时：**优先展示标准合约**；非标准在该格显示 **角标 `调`**，悬停展示完整合约简称、代码及 IV/Δ
3. **虚值规则不变**：非标准合约同样仅展示虚值（购 K≥S、沽 K<S）
4. **点选入交易列表**：加入 **用户点击的那条**（标准或非标准）；合约名称保留尾缀字母
5. **无报价**：仍置灰 `--`，不可点选

**T 型报价展示（开关 = 开，已确认：调整子行）**

| 维度 | IV 热力图 | T 型报价 |
|------|-----------|----------|
| 非标准展示 | 同列角标 `调` + 悬停详情 | 每个行权价 K 下：**标准行在上**；若有非标准则 **调整子行在下**（缩进、浅色背景，标签「调」） |
| 点选 | 点格子选对应合约 | 标准行 / 调整子行 **分别可点**，三态逻辑与热力图一致 |
| 优先级 | 同列标准优先展示 | 标准行为主行，非标准为子行 |

**数据与计算**

- IV、Greeks、着色规则与标准合约 **完全一致**（仍基于中间价，见 5.0）
- HV 分位着色 **不参与** 非标准合约 IV 统计；`vmin`/`vmax` 仍由标的 10 年 HV 20/80 分位决定（已确认）
- 交易列表、导出 CSV 须带字段 **`合约类型`**：`标准` / `非标准`

**边界与降级**

| 场景 | 行为 |
|------|------|
| 数据源无法区分标准/非标准 | 设置项置灰 + 说明「当前数据源不支持」；始终仅标准 |
| 仅有非标准、无标准同档报价 | 开关关：该格 `--`；开关开：展示非标准 |
| 除权期外通常无非标准 | 开关开但链上无非标准合约时，界面与关一致，不额外提示 |
| 用户开启开关但未刷新 | 仍展示上次缓存的标准链；图例可提示「设置已变更，请刷新」 |

**不在本需求范围（后续可选）**

- 按合约单位差异单独换算 Greeks
- 非标准合约单独色板
- 自动检测除权日并默认打开 Toggle

> **设计原则**：默认体验与现网一致（仅标准）；高级用户显式开启后才混入调整合约，避免干扰日常扫链。

### 5.4 T 型报价（P1）

#### 5.4.1 月份选择

#### 5.4.2 列结构（购/沽两侧对称，Greeks 均以中间价计算）

| Call 侧（购） | 中间 | Put 侧（沽） |
|---------------|------|--------------|

**表头示例**

```
C买 C卖 CIV CΔ CΓ CΘ CV |  K  | P买 P卖 PIV PΔ PΓ PΘ PV
```

- **购侧 / 沽侧单元格**支持三态点选（做多 → 做空 → 移除），逻辑与热力图一致
- 当前选中格/行高亮（绿框做多、红框做空）
- **页面下方内嵌同款交易列表抽屉**（字段、汇总、操作按钮与热力图页一致）

#### 5.4.3 与热力图的差异

| 维度 | IV 热力图 | T 型报价 |
|------|-----------|----------|

| 选腿方式 | 点击格子 | 点击购/沽侧任意列 |

### 6.1 MVP 数据源策略

| 角色 | 来源 | 用途 | 频率 |
|------|------|------|------|

| **历史** | EastMoney / AKShare | ETF 日线（HV 分位） | 日更 |

### 6.2 期权链拉取范围（P1）

| 设置：显示非标准合约 | 合约元数据 | 批量报价范围 | 目标 |
|---------------------|------------|--------------|------|
| **关**（默认） | 可拉全链元数据后 **服务端过滤** 标准合约 | **仅** 标准 + 虚值 + ±20% 档位所需合约 | 减少 Sina/东财询价次数与响应体积 |
| **开** | 标准 + 非标准 | 上述范围 + 非标准虚值合约 | 除权期完整视图 |

- 元数据（上交所合约列表）可一次拉取；**报价批量请求**必须按上表裁剪，禁止在开关关闭时对全链 300+ 合约询价
- 热力图/T 型报价 API 读取用户设置，不依赖前端本地二次过滤作为唯一手段

### 6.3 MVP 明确不做

- 不逐合约轮询 Sina 实时报价
- EastMoney 失败时不切换 Sina 全量刷新，而是返回缓存 + 告警

### 6.4 数据字段（期权合约）

| 字段 | 来源 | 用途 |
|------|------|------|
| 合约代码、名称 | EastMoney / Sina 链 | 展示、标识 |
| **合约类型** | 链解析（简称尾缀 / 上交所字段） | 标准/非标准过滤与展示 |
| 行权价、到期日、剩余天数 | EastMoney / Sina 链 | 矩阵定位、T 表 |
| 买价、卖价 | EastMoney | 中间价与委托价计算 |
| 中间价 | (买+卖)/2 | **IV 与 Greeks 计算基准** |
| 成交量、持仓量 | EastMoney | 展示（P2 可加流动性过滤） |
| 标的现价 | EastMoney | ATM 判定、IV 计算 |

### 6.5 降级与异常

| 场景 | 产品行为 |
|------|----------|
| EastMoney 请求失败 | 展示上次缓存快照 + 顶部黄条告警 |
| 个别合约无报价 | 热力图格子置灰 `--` |
| 非标准合约被设置隐藏 | 该档若有仅非标准报价，不请求其报价，格子置灰 |
| IV 无解（深度虚值） | 格子置灰，不可点选 |
| Sina 辅助开启但失败 | 忽略，不影响主流程 |
| 非交易时段 | 停止主动刷新，展示最后快照 |

## 11. MVP 验收标准

1. 首页三张 ETF 卡片展示 **蜡烛图** 日线图（OHLC），非柱状图
2. 热力图页下方展示 **完整交易列表抽屉**（含 IV 与全套 Greeks、组合汇总）
3. T 型报价两侧均展示 IV、Δ、Γ、Θ、V，且以中间价计算
4. 全站 IV/Greeks/热力图着色统一遵循 `Mid = (Bid1+Ask1)/2`
5. 热力图纵轴为 **4 个挂牌月**（当月/下月/两季月）；横轴为 **现价 ±20%** 范围内的行权价，表头与列严格对齐；左侧沽（K<S）、右侧购（K≥S），中间有现价竖线
6. 每格显示 `IV (xx.xx%)` 与 `Δ 0.xxx`，颜色范围由 10 年 20 日 HV 20/80 分位约束
7. 三态点选正确驱动交易列表方向（做多/做空/移除）
8. 交易列表可改报价方式、数量，委托价与 Greeks 自动更新
9. 组合 Delta 汇总与 Notebook 手算结果一致（中间价口径）
10. T 型报价顶栏可切换 4 个挂牌月份 Tab；购/沽侧三态点选与热力图联动
11. 热力图与 T 型报价页均内嵌交易列表抽屉；抽屉提供复制、导出、跳转完整列表；MVP 无直连下单
12. 本机浏览器完成全流程，**不依赖 Sina 实时接口**
13. EastMoney 异常时展示缓存快照 + 告警，不白屏
14. **（P1）** 设置中开关默认关时，热力图与 T 型报价 **仅含标准合约**；后端 **未对非标准合约发起批量询价**，接口响应体积小于「全开」场景
15. **（P1）** 设置开启后，非标准合约出现在对应虚值档位；同列标准与非标准并存时标准优先、非标准角标 `调`；点选入交易列表的合约代码与类型正确
16. **（P1）** T 型报价在开关开启时，行权价下展示 **调整子行**（标准行在上），子行可独立三态点选
17. **（P1）** 开关状态保存在设置 API；热力图/T 型报价只读同步；变更后提示用户手动刷新，不自动静默重拉全链
